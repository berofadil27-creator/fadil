# VEYRA — Discover What's Real.

Plateforme d'analyse de contenus générés ou modifiés par intelligence artificielle.

## État du projet
- [x] Phase 2 — Site web (Next.js + TypeScript) : `apps/web`
- [ ] Phase 3 — Backend FastAPI : `services/analyzer`
- [ ] Phase 4 — Première vraie analyse photo
- [ ] Phases 5 à 10 — voir le cahier des charges

Les dossiers vides suivent l'organisation du cahier des charges et seront remplis aux phases suivantes.

## Lancer le site (Windows / PowerShell)
Prérequis : Node.js 20.9 ou plus récent.

    cd Documents\VEYRA\apps\web
    npm install
    npm run dev

Puis ouvrir http://localhost:3000
